# Docusaurus (Meta Open-Source Project)

## Overview
- Not an independent company — Docusaurus is a free, open-source project originated and backed by Meta (formerly Facebook) under Meta's Open Source program. It has no independent ownership structure, revenue, or business entity separate from Meta's open-source initiative.
- Project originated at Facebook to standardize documentation across the company's many open-source projects; publicly released and has been maintained as an open-source project for roughly a decade (Docusaurus 2 was a full rewrite released in the early 2020s).
- "Employee count" does not apply in the traditional sense: the project is maintained by a mix of Meta-affiliated engineers and independent open-source contributors. Public reporting indicates contribution activity is notably concentrated in a single lead maintainer who is not a Meta employee, alongside broader community contributions.

## Business Model
- No business model — Docusaurus is entirely free and open-source (MIT licensed), with no paid tiers, subscriptions, or usage-based fees of any kind.
- Meta funds the project as a "good-citizen" investment in the open-source ecosystem rather than as a revenue-generating product; there is no monetization strategy attached to the project itself.
- Target user: Open-source project maintainers, developer-tool companies, and technical teams who want a free, static-site-generator-based documentation website (built on React) without ongoing software costs.

## Product & Positioning
- Core differentiator: A free, highly customizable static-site generator purpose-built for documentation, built on React, with strong versioning support, internationalization (i18n), and a plugin ecosystem — widely adopted across the open-source/developer-tools community (e.g., React Native, Redux, and many other projects use it).
- Platform availability: Self-hosted static site output (deployable anywhere — GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.); no hosted SaaS offering from Meta itself.
- Key features: Markdown/MDX-based content authoring, built-in versioned docs, search integration (typically via Algolia DocSearch), theming/customization via React components, and a plugin architecture for extensibility.

## Financial Profile (estimates where not disclosed — always label as "estimated")
- Revenue: None — Docusaurus generates no direct revenue; it is a cost center for Meta's open-source program, not a business.
- Customers: Not applicable in a commercial sense; adoption is measured by GitHub stars/usage rather than paying customers. It is widely used across the open-source and developer-tools ecosystem as a default choice for project documentation sites.
- Funding history: Not applicable — funded entirely through Meta's internal open-source investment rather than external venture capital, since it is not a standalone company.
- Growth trajectory: Adoption (rather than revenue) continues to grow as the default "docs as code" static site generator for many open-source projects, benefiting from Meta's continued (if modest) maintenance investment and community contributions.

## Competitive Position
Docusaurus is not a market competitor in the traditional sense — as a free, Meta-backed open-source tool, it exerts significant downward pricing pressure on commercial documentation platforms (GitBook, Mintlify, ReadMe) for the segment of users who need self-hosted, no-cost documentation and are comfortable with static-site tooling and self-managed hosting/search. Its "moat" is Meta's backing and broad ecosystem trust, but it competes on cost and control rather than on hosted convenience, AI features, or interactive API tooling — meaning it complements rather than directly displaces the commercial SaaS players in this space for teams that value convenience over cost control.

## Unit Economics & Monetization

- **Primary revenue source:** Free open-source project (MIT-licensed); no direct monetization — maintained by Meta Open Source as infrastructure supporting Meta's own documentation needs and developer goodwill
- **Secondary monetization:** None; no paid tiers, hosting fees, or support contracts from the project itself (third-party hosts like Vercel/Netlify monetize deployment separately, not Docusaurus)
- **Growth/acquisition model:** Free/no monetization — adoption is driven entirely by GitHub visibility, community contributions, and default-choice status among React/JS developers building documentation sites.
- **Estimated CAC (customer acquisition cost):** $0 — free open-source project with no company and no sales/marketing spend attributable to "customer" acquisition.
- **Estimated LTV (customer lifetime value):** $0 — no revenue is captured from users regardless of usage duration or scale.
- **LTV:CAC ratio (implied):** N/A
- **User demographics:** Individual developers, open-source maintainers, and engineering/DevRel teams at companies of all sizes building technical documentation sites; global, skewing toward JavaScript/React ecosystem users.
- **Estimated user geography:** Global/Distributed, top countries: United States (~22%), India (~18%), Brazil (~9%), China (~8%) — estimated from GitHub contributor/star geography and global JS open-source community reach, not disclosed.

*All figures in this section are estimates based on business-model archetype and publicly available pricing — none of these companies disclose actual CAC/LTV. Treat as directional only.*
