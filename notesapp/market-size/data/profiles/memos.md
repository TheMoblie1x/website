# Memos

## Overview
- Pure open-source community project (MIT license); no company, no VC funding, no formal ownership structure beyond the GitHub organization "usememos."
- No formal founding date/HQ/named founders disclosed publicly; maintained as a community/maintainer-driven GitHub project rather than an incorporated business.
- Employee count: not applicable — it is a volunteer/open-source maintainer project rather than a company with employees.

## Business Model
- No business model: Memos has no paid tiers, no company monetizing it, and no telemetry. It is entirely free and MIT-licensed; the only "cost" to users is the infrastructure they choose to self-host it on (a Go binary or Docker container with SQLite/MySQL/PostgreSQL).
- Pricing: N/A — free and open-source; users pay only for their own server/hosting, not for the software.
- Target customer: individual self-hosters and privacy-conscious users wanting a lightweight, Markdown-native "quick capture" timeline app (daily notes, snippets, short-form thoughts) rather than a full workspace.

## Product & Positioning
- Core differentiator: minimalism and speed — a timeline-first, chronological Markdown feed for short-form notes, explicitly positioned against heavier "all-in-one workspace" tools; single-binary self-hosting with no telemetry.
- Platform availability: Self-hosted only (single Go binary or Docker container); accessed via web browser; REST and gRPC APIs available for building custom clients/integrations.
- Key features: chronological note timeline, Markdown-native editing, lightweight footprint, REST/gRPC API for extensibility, full data ownership with zero telemetry.

## Competitive Position
