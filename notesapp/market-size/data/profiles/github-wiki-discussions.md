# GitHub Wiki & Discussions (Microsoft/GitHub)

## Overview
- Public subsidiary product line: GitHub, Inc. has been a wholly owned subsidiary of Microsoft Corporation since its 2018 acquisition (~$7.5B). GitHub Wiki and GitHub Discussions are bundled features within the core GitHub platform, not standalone products.
- GitHub founded 2008 (Chris Wanstrath, PJ Hyett, Tom Preston-Werner, Scott Chacon); acquired by Microsoft in 2018. GitHub Discussions launched in beta 2020, generally available to all repos in 2021.
- Employee count: not broken out separately; GitHub operates as a Microsoft business unit (Microsoft overall has ~220,000 employees; GitHub-specific headcount not separately disclosed).

## Business Model
- Not independently monetized — Wiki and Discussions are free features included with any GitHub repository/organization plan, functioning as retention and community-engagement tools that support GitHub's core per-seat subscription business.
- GitHub's overall pricing (as of 2026): Free tier (unlimited public/private repos, includes Wiki/Discussions); Team at ~$4/user/month (annual billing); Enterprise Cloud at ~$21/user/month (annual billing, promotional/list pricing varies, standard post-promo enterprise pricing requires sales contact). GitHub Copilot is now billed separately/usage-based (Pro $10, Pro+ $39, Business $19, Enterprise $39 per user/month as of mid-2026 pricing changes).
- Target customer: any GitHub repository owner/organization — open-source maintainers (free) up to large enterprises (Enterprise Cloud/Server) needing project documentation (Wiki) and community Q&A/announcements (Discussions) co-located with code.

## Product & Positioning
- Core differentiator: tight integration with source code — Wiki and Discussions live directly alongside issues, pull requests, and repo activity, removing the need for a separate documentation/forum tool for many open-source and small dev-team projects.
- Platform availability: web, GitHub mobile app, GitHub CLI/API access; Wiki content stored as its own Git repo (clonable/editable via Git).
- Key features: Wiki — Git-backed Markdown pages, revision history, per-repo access control; Discussions — threaded Q&A/announcement/polls format, category customization, integration with issues (convert issue to discussion), used heavily by open-source projects (e.g., Next.js, PyTorch community discussions) as a support forum.

## Financial Profile (estimated)
- Revenue: GitHub's standalone revenue is not separately broken out by Microsoft in public filings; third-party estimates have placed GitHub revenue in the $1–2B/year range in recent years, with GitHub Copilot cited by Microsoft as a major growth driver — but this covers all of GitHub, not Wiki/Discussions specifically, which generate no direct revenue.
- Adoption: GitHub reports 100M+ developers and 400M+ repositories on the platform (Microsoft/GitHub public figures from recent years); Wiki/Discussions usage is a subset — Discussions is enabled on a large share of major open-source repos but exact usage numbers aren't separately disclosed.
- Funding: N/A — fully owned by Microsoft (public company, NASDAQ: MSFT); no independent funding history since the 2018 acquisition.
- Growth trajectory: Wiki has been largely stable/legacy for years; Discussions has grown steadily since 2021 GA as more open-source projects adopt it in place of third-party forums (Discourse, Slack, Gitter).

## Competitive Position
GitHub Wiki and Discussions aren't sold as standalone products, so their "competition" is indirect — they reduce the need for smaller teams and open-source projects to adopt separate tools like Confluence, BookStack, Discourse, or Discord/Slack for documentation and community discussion. Their moat is pure bundling and integration convenience (zero extra cost, native to where code already lives), but they are feature-limited compared to purpose-built wikis (Confluence, XWiki) or forums (Discourse), making them a default/good-enough choice rather than a best-in-class one for teams with serious documentation or community needs.

## Unit Economics & Monetization

- **Primary revenue source:** Free bundled feature — Wiki and Discussions generate no direct revenue; they support retention/engagement for GitHub's core per-seat subscription business (Free/Team/Enterprise Cloud).
- **Secondary monetization:** None standalone; indirectly supports upsell to paid GitHub tiers and Copilot (now billed separately/usage-based) by increasing platform stickiness.
- **Growth/acquisition model:** Free/bundled — distributed automatically to every repository/organization as part of GitHub's core product; no separate acquisition motion, riding entirely on GitHub's overall PLG/enterprise-sales funnel.
- **Estimated CAC (customer acquisition cost):** ~$0 standalone CAC — Wiki/Discussions are not sold or marketed independently; any acquisition cost is absorbed into GitHub's overall per-seat subscription CAC (not broken out).
- **Estimated LTV (customer lifetime value):** $0 attributable directly to Wiki/Discussions (no direct revenue); their value is retention-driving within GitHub's much larger per-seat LTV (Team ~$4/user/month, Enterprise Cloud ~$21/user/month), which is out of scope for this feature-level profile.
- **LTV:CAC ratio (implied):** N/A — not independently monetized; adjacent/bundled feature of a much larger paid platform.
- **User demographics:** Any GitHub repository owner or organization — open-source maintainers and small dev teams (free tier) up to large enterprises (Enterprise Cloud/Server); global, developer-centric audience.
- **Estimated user geography:** Global/Distributed, top countries: United States (~20%), India (~14%), Germany (~6%), United Kingdom (~5%), Brazil (~4%) — estimated from GitHub's disclosed global developer-base distribution (100M+ developers), not disclosed.
