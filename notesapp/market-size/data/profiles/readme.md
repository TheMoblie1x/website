# ReadMe

## Overview
- Private company, VC-backed; no parent company.
- Founded in 2014 (originated as ReadMe.io, backed by Y Combinator). HQ in San Francisco, California.
- Employee count estimate: approximately 82 employees as of mid-2026 (source: company data aggregation).

## Business Model
- SaaS subscription for API documentation and developer portal software, tiered by feature access and usage (API log volume).
- Pricing tiers (as of 2026, source: ReadMe official docs and aggregator sources): Free tier; Startup at $79/month; Business at $349/month; Enterprise at $3,000+/month (all paid plans billed annually). Add-ons include "Ask AI" at $150/month per paid plan, extended request history/logs at $100/month, and a Developer Dashboard priced separately (~$100/month for 5M API logs, then $10 per additional million).
- Target customer: Developer-facing companies (API-first SaaS and platform companies) needing interactive, branded developer documentation and API reference portals.

## Product & Positioning
- Core differentiator: Interactive, branded developer hubs with live "try it" API testing built directly into documentation, plus analytics on API usage/adoption by customers — positioning docs as a growth/adoption tool, not just reference material.
- Platform availability: Web-based SaaS platform, OpenAPI/Swagger import support, custom domains for white-labeled developer portals.
- Key features: Interactive API explorer (live API calls from docs), API usage analytics per user/customer, versioned documentation, and generative AI features (Ask AI) layered onto existing docs content.

## Financial Profile (estimates where not disclosed — always label as "estimated")
- Revenue: Not publicly disclosed; no reliable ARR figure found in available sources.
- Customers: Not disclosed in available sources; markets itself broadly to API-first technology companies.
- Funding history: Raised a $9M Series A led by Accel in August 2019, bringing total disclosed funding to roughly $10M including earlier Y Combinator/seed backing (source: TechCrunch). No publicly announced funding rounds since 2019 — a six-year-plus gap as of 2026, which may indicate capital efficiency/profitability or a slower, self-funded growth phase (estimated interpretation, not confirmed).
- Growth trajectory: The long gap since its last raise, combined with continued product investment (e.g., Ask AI, Developer Dashboard add-ons), suggests steady organic growth rather than venture-fueled hypergrowth.

## Competitive Position
ReadMe holds a strong, differentiated position in the API-documentation-as-a-product niche, particularly for companies that want documentation to double as a self-serve sales/adoption tool via interactive API testing and usage analytics — a feature set that generic wikis (GitBook, Outline) don't offer. Its moat is moderate: newer, faster-growing entrants like Mintlify are targeting the same developer-docs niche with more aggressive AI-native positioning and funding, which could erode ReadMe's position if it doesn't match that pace of innovation.

## Unit Economics & Monetization

- **Primary revenue source:** Per-project/per-seat SaaS subscription for API documentation hosting (tiered plans up to Enterprise)
- **Secondary monetization:** Enterprise add-ons (custom domains, advanced analytics/metrics, SSO, versioning at scale); no ads
- **Growth/acquisition model:** Self-serve + inside sales (PLG) — free trial and transparent tiered pricing drive developer/DevRel signups, with inside sales engaging larger API-platform customers.
- **Estimated CAC (customer acquisition cost):** $800–$2,500 (estimated) — dev-tool PLG motion with content/SEO-driven signups and light-touch sales for larger accounts.
- **Estimated LTV (customer lifetime value):** $4,000–$12,000 (estimated) — assumes ~$1,500–$4,000 average annual contract value and a ~3-year customer lifetime.
- **LTV:CAC ratio (implied):** ~5:1 (estimated)
- **User demographics:** API-first software companies and platform teams; DevRel, developer experience, and engineering teams are primary buyers; skews US/tech-hub, mid-market SaaS companies.
- **Estimated user geography:** North America, top countries: United States (~65%), United Kingdom (~8%), India (~6%), Canada (~5%) — estimated from HQ location (San Francisco, CA) and dev-tool community reach, not disclosed.

*All figures in this section are estimates based on business-model archetype and publicly available pricing — none of these companies disclose actual CAC/LTV. Treat as directional only.*
